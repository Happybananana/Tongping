同频 V0.6.10 · 四人轨迹交汇（从已安装的双人 V0.6.9 升级）

本补丁只有新增的四人交汇前端代码与版本号/文档。

1. 解压 ZIP，打开 GitHub 仓库 Happybananana/Tongping 的 main 分支。
2. 将 ZIP 内所有内容拖入仓库根目录，并覆盖同名文件，点击 Commit changes。
3. 等待 Vercel 正式部署，刷新后检查版本显示 0.6.10。
4. 在「沿途车站 → 轨迹交汇」可选 1～3 位好友，包含你自己最多 4 人。

这次无需 SQL！以前的 V0.6.9 SQL 已经提供所需的双向授权和 RPC。
不要重复执行 Supabase schema.sql，也不需要重新配置高德 Key。

如果当前仓库还停在 V0.6.8 或更早版本，本增量补丁不适用。
