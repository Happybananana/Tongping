# 同频 V0.6.9 · WHERE WE CROSS / 轨迹交汇

基于 V0.6.8 的旅行年鉴继续升级。新增好友双人历史旅行地图，
支持选择好友、双向授权、地理足迹、交汇站、双方旅行记忆与交互地图缩放。

## 直接覆盖升级（无需任何本地脚本、无需 GitHub Actions）

1. **先在 Supabase SQL Editor 执行单独提供的 `Tongpin_V0.6.9_SQL.sql`。**
   这份独立 SQL 已包含 V0.6.8 日期/坐标基础迁移和 V0.6.9 双向分享权限迁移，
   因此既可以从 V0.6.7 升级，也可以在已部署 V0.6.8 的项目上重复安全执行；不清空旧数据。
2. 将 ZIP 解压，将其**内部全部文件与文件夹**拖到 GitHub 仓库根目录，
   按原目录结构覆盖；提交更改即可触发原 Vercel 自动部署。
3. 检查右上角 `0.6.9`；进入「沿途车站 → 轨迹交汇」，
   两个好友账号分别开启分享并验证地图。

本 ZIP 包同时带有 V0.6.8 旅途年鉴文件和 V0.6.9 文件，所以源码能覆盖
V0.6.7 / V0.6.8 的常见升级状态；只需执行单独提供的合并 SQL，即可按顺序补齐数据库升级。

## 你将获得什么

- 内置世界地理轮廓地图，不需新的地图 Key；沿用高德地点搜索与 GCJ-02 坐标。
- 双方**都主动开启**才查询到历史公开足迹，私人记录从数据库查询端排除。
- 以共享地点 ID 精确识别交汇；同日到访不推断同行。
- 可拖动缩放的地图、两色旅行轨迹、交汇卡和双方的回忆。
- 游戏、动画、原高德搜索、旅行年鉴和个人隐私配置保持独立。

## 需注意

旧地点如果没有保留经纬度，不会凭地点名虚构坐标，暂时不能显示在地图上。
地图为大陆/国家轮廓级别，不包含真实道路或乘车路线。

升级记录、SQL 隐私约束与完整验收见 `docs/FEATURES_V069.md`。

本地验证（非必须）：`npm run test:features && npm run test:search && npm run build`。
