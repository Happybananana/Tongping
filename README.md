# 同频 V0.6.2 · 批量导入智能匹配

本版本以 V0.6.1 为基础，**保留 VIDEO CLUB 与 COLLECTION 双主题、共享作品、个人评分、圈内讨论、旅行专页和现有 Supabase 配置**。

主要升级：

- 批量导入不再每 8 条等待人工点击「继续匹配」，而是逐批自动连续完成已勾选的未匹配条目。
- 控制并发（最多 2 个请求）、发起间隔（≥ 750ms）和超时，避免对网络数据源突发请求。
- 高置信度匹配自动预选：准确标题／类别／年份匹配或明确 Bangumi ID；相似标题或同名歧义仍需要人工确认。
- 新增导入进度条、暂停/继续、失败行单独重试。
- 不自动写入数据库；**必须点击最终的确认导入**。已有个人评分不被覆盖，未匹配到的作品仍保留手动建档兜底。

详细规则见 [docs/IMPORT_V062.md](docs/IMPORT_V062.md)。

## 升级方式

如果你正在使用 V0.6.1，可用升级补丁按目录覆盖仓库文件，或下载完整项目文件解压上传到 GitHub 仓库根目录。

- **无需 Supabase SQL 迁移**。
- **无需新环境变量**。
- 已在 V0.5.7 执行过 `supabase/migration_v057.sql` 的项目无需重复执行。
- 上传前请备份目前的 GitHub 分支，并确保仓库里的 `.env` 等私密文件不被公开提交。

## 开发 / 测试

`npm install` 后可执行 `npm run build`、`npm run test:features`、`npm run test:search`。

本地已完成 Node 自动化测试和独立 HTML 预览的交互检查；第三方真实网络联调及 Vite 生产构建需要部署后确认。
