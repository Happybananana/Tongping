# 同频 V0.5.3 — 首页动态增强 + 录像柜信息强化

本版在 V0.5.2 的基础上继续打磨，重点做了两件事：

1. **首页「朋友正在播放」更像真正的店内节目单**
2. **「我的录像柜」增加更清晰的个人概览信息**

## 本次更新

### 1) 首页动态区升级
- 「朋友正在播放」加入 **分页**，避免首页无限拉长。
  - 每页 8 条动态
  - 显示当前页码与总页数
- 第一条动态升级为 **重点卡片**，信息权重更高，更有“本期推荐”感。
- 评分徽标强化：
  - 分数字号更醒目
  - 采用更有 VHS 海报感的黄色分数牌
  - 标签和注释区做了更清晰的层级处理

### 2) 我的录像柜增强
- 在磁带架上方新增 **个人概览条**：
  - 已收藏磁带数
  - 我的平均评分
  - 当前偏好（动画 / 游戏）与待评分数量
- 保留现有 VHS / MIXTAPE 风格，不改变原有收藏结构。

### 3) 保留 V0.5.2 的修复
- 首页「每一个瞬间都值得按下 REC。」文案区域避免与下方卡片重叠
- 好友频道排行榜保留：
  - 前三名主舞台
  - 完整榜单分页
  - 保持封面同比例展示
