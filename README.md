# 同频 V0.6.3 · 批量导入安全勾选

本版基于 V0.6.2，只调整批量导入的搜索与默认勾选联动，**不改变双主题、评分、帖子、共享库或 Supabase 数据结构**。

## 导入时的默认勾选规则

| 导入行类型 | 默认勾选 | 说明 |
|---|---|---|
| 已准确匹配圈内共享库 | 是 | 已有个人记录不会覆盖，重复或错误行禁用 |
| 在线搜索后高置信度自动匹配 | 是 | 可以主动取消勾选或更换候选 |
| 人工审核后明确选择网络候选 | 是 | 点击候选作品自动勾选；取消候选则取消勾选 |
| 找到候选但仍未确认 | 否 | 待审核行不会进入最终导入清单 |
| 在线无结果、请求失败或尚在搜索 | 否 | 不会擅自按表格名称建档 |
| 不合法、表格重复、已有个人记录 | 禁用 | 不参与联网请求或导入 |

**搜索队列与勾选状态彻底分离**：即使未勾选，所有有效且不在共享库的作品仍会自动连续联网搜索；最多 2 个并发，每次发起间隔至少 750ms。最后仍须人工确认导入。

如确实需要为搜不到的条目建档：先勾选「允许手动建档」，然后逐行手动勾选这些作品。该选项不会批量自动选中未匹配行；关闭它时，未确认作品会恢复未勾选。

## 升级方式

从 V0.6.2 升级：按目录覆盖补丁文件，或使用完整项目源码替换 GitHub 仓库中的对应文件。

- 不需要新增 SQL 或调整 Supabase 数据。
- 不需要更新 Vercel 环境变量。
- V0.5.7 起的帖子表迁移若已执行，不要重复重建数据库。
