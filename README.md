# 同频 V0.6.10 · 轨迹交汇四人版（V0.6.9 增量升级）

本更新以 **已部署的双人 V0.6.9** 为基线，仅增强「沿途车站 → 轨迹交汇」；
保留原有旅途年鉴、高德地点搜索、双向旅行足迹分享和数据库结构。

## 无需 SQL 的 GitHub 直接覆盖升级

1. 解压 `Tongpin_V0.6.10_四人交汇_从V069直接覆盖.zip`。
2. 把解压出的文件和文件夹（包括 `src/`、`docs/`、`package.json`、`index.html`）
   拖入 GitHub 仓库 `main` 分支**根目录**，以原路径覆盖同名文件并提交。
3. 待 Vercel 自动构建部署后，网页右上角应显示 `PLAYING NOW · 0.6.10`。
4. 打开「沿途车站 → 轨迹交汇」，在已开启分享的状态下选择 1～3 位好友。

**这次不需要执行任何 SQL，不需要重新申请 AMAP_WEB_KEY，也不需要启动 GitHub Actions。**
不建议重新运行以前的 Supabase 全量 schema.sql。

## 主要变化

- 最多四人：登录用户自己 + 1～3 位选中的圈内好友。
- 可随时切换双人、三人、四人模式；更改选人后重新获取已授权的历史足迹。
- 按至少两人、至少三人或当前全员筛选同一共享地点的交汇站；可显示 4 张个人回忆卡。
- 继承 V0.6.9 已有的数据库安全 RPC：双方均主动开启分享、本人记录圈内可见、已去过且有坐标。
- 不使用实时定位，不把路线示意线说成真实出行路径。

升级细节与验收项见 `docs/FEATURES_V0610.md`。
