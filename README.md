# 同频 V0.5.7 · COLLECTION / VIDEO CLUB / 圈内讨论

在 V0.5.6 基础上升级，保留现有 Vercel + Cloudflare + Supabase、Bangumi/Jikan/IGDB/RAWG 搜索，以及 VIDEO CLUB + RAILWAYS。

## 新功能

**P1 · 批量收藏导入**：进入「我的录像柜」→「批量导入表格」，选择 `.csv` / `.xlsx`，自动识别作品名、类别、个人分数、状态、短评和年份。先展示逐行预览，匹配同圈共享作品/公共条目；已存在的个人记录不会覆盖；同表内重复作品不会重复导入。未匹配行**只有手动勾选允许创建共享条目**后才能导入。默认仅自己可见，可选择公开到圈内。

支持自动识别前 10 行中的表头；支持 UTF-8/GB18030 CSV；每次最多 300 行、2 MB。**旧版 `.xls` 不支持直接解析**，请在 Excel/WPS 中另存 `.xlsx` 或 `.csv`。当前未匹配作品不会自动调用 Bangumi 搜索来猜测 ID/封面，以避免同名误匹配；创建后可在「找片」中进一步完善。

**P2 · 个人统计**：个人总记录、有效评分均值、完成率、分类分布、状态分布、个人评分直方图，以及**作品发行年份分布**（不是观看/通关日期）。依据你已保存的个人记录计算，不涉及其他人的私密数据。

**双主题切换**：顶部 `◐ 主题` 或「我的录像柜」的“页面主题”按钮。默认 VIDEO CLUB；COLLECTION 是参考 SJG 简洁收藏柜界面设计的独立明亮样式，偏浅灰/蓝色、轻阴影、规整内容。主题偏好只保存在当前浏览器 `localStorage`，不触碰 Supabase。旅行子页面继续保留自己的铁路场景布局。

**圈内讨论**：桌面「圈内讨论」导航，手机「好友频道 → 进入圈内讨论」。发表帖子需明确指定一部现有动画/游戏，可写标题、正文并标记剧透。帖子列表按动画/游戏筛选，支持分页；帖子详情支持其他圈友回复；作者可删除自己的帖子和回复。作品详情页也会展示关联帖子。旅行地点暂不开放帖子。

## 升级现有线上网站（必读）

1. 建议先保留当前 GitHub 仓库的稳定提交作为回退点。
2. **先在现有 Supabase 项目 SQL Editor 执行** `supabase/migration_v057.sql`。这是增量迁移，只添加 `circle_posts`、`post_comments` 和对应的 RLS 策略/索引。**不要重新执行 `supabase/schema.sql`**，不要清空数据库。
3. 把本项目解压后的文件按目录覆盖 GitHub 根目录。不要直接上传 ZIP，也不要额外套一层版本文件夹。
4. Vercel 构建需安装新依赖 `read-excel-file`；无需添加新的环境变量。 `npm install && npm run build` 可在有网络的环境验证。
5. 验证新主题、少量 CSV 导入、圈内发帖/回帖；用两个账号分别检查同圈可见性及非同圈不可见性。

如果尚未执行 SQL，原来的评分与搜索仍可用，但讨论页会提示迁移尚未执行。

## 安全与边界

- 本地解析表格，只有点击最终“确认导入”才写入 Supabase；不会自动把全表发送给外部搜索服务。仅作者可删除自己帖子/回复；读写仅同圈可见由 PostgreSQL RLS 执行。
- 导入新增的手动条目可能和已有的不同语言版本同名，请在预览里核对；暂不跨数据源自动识别所有异名作品。
- 讨论帖为文字，不支持上传图片或 Markdown/富文本；正文使用 HTML 转义，避免脚本注入。
- 讨论数据加载最多读取最近 200 条帖子 / 600 条回复，适合 5～15 人圈子；扩大规模应改为数据库端游标分页。
- 本环境未连接你的真实 Supabase，也无法联网安装 npm 依赖，因此**尚未完成 Vite 正式打包和在线 RLS 联调**。本地已有 52 项原有接口/数据测试和 7 项新增导入/统计测试通过；Chromium 无外部依赖的模拟界面可供审美验收。

## 开发自检

```sh
npm install
npm run test:search
npm run test:features
npm run build
```

`visual-preview.html` 是用实际 V0.5.7 页面模板与 CSS 注入模拟数据生成的独立交互预览，不会连接 Supabase 或实际写入记录；在实际网站中以上新功能需连接已迁移的数据库。
