# 同频 V0.5.8 · POSTER INDEX

延续 VIDEO CLUB 录像店，同时把 COLLECTION 升级为真正独立的编辑式影像资料库主题。

## 核心新增

- **个人海报墙**：MIXTAPE / 海报墙 / 详细列表，三视图自由切换。海报墙每页 24 项，兼容分类、状态和排序，封面不拉伸。
- **帖子作品搜索**：搜索中文名或原名，显式选中作品后才能发帖，避免大下拉框或误选。
- **圈内帖子上首页**：最新 3 帖展示在首页的好友动态下方，包含作品、作者、回复数和剧透隐藏。
- **下载导入模板**：导入弹窗内直接下载 Excel (.xlsx) 或 CSV。
- **真正的双主题**：VIDEO CLUB 保留复古录像店；COLLECTION 使用独立的图文编辑布局、深松绿、米白、收藏卡和海报资料库。

## 部署

- 从 V0.5.7 升级：**无需新的数据库迁移，也无需新增环境变量**。
- 从 V0.5.6 或更早升级：请先在现有 Supabase 项目执行 `supabase/migration_v057.sql`，以创建并保护帖子/回复表。
- 将完整源码的内容放到 GitHub 仓库根目录。不要把整层 `tongpin-v058/` 套进去，亦不要上传真正的 `.env` 或服务器密钥。
- 提交后等 Vercel 自动构建，建议检查两套主题、发帖绑定及帖子在首页出现的情况。

细节和测试步骤见 [docs/FEATURES_V058.md](docs/FEATURES_V058.md)。
