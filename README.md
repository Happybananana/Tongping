# 同频 V0.6.1 · COLLECTION 页面精修

## 本版更新

本版仅调整 **COLLECTION** 主题中的「发现作品」和「圈内榜单」视觉，不修改 API、数据库、评分模型、权限、主题切换及分页逻辑。

- 发现作品：独立的编辑式资料库页头、纸张质感搜索框与墨绿索引卡；搜索行为仍使用原有共享库及外部 API。
- 圈内榜单：独立的「我们共同的作品榜单」页头，右侧展示真实排行榜前三部；原录像店唱片展示保留在 VIDEO CLUB，COLLECTION 改为深松绿、纸白、鼠尾草绿的榜单舞台，减少红黄荧光色。
- 榜单的前 3 名与其余作品分页、平均分 / 评分分歧切换、≥3 人过滤，保持原逻辑。
- 手机端重排搜索页头与排行榜引导，保留可读性。

## 从 V0.6.0 升级

补丁包含：`src/main.js`、`src/v061-collection-pages.css`、`package.json`。替换和新增对应路径即可。若使用完整包，请确保文件位于 GitHub 仓库根目录。

无需新的 Supabase SQL 或 Vercel 环境变量。

## 验证

见交付说明。预览使用模拟数据；完整构建及真实 Supabase 联调需要部署环境确认。

## 1. 我的收藏 → 海报墙

- **海报封面不再显示任何额外英文标题黑块**：页面只覆盖左上角收藏状态、右下角个人评分；作品名、年份、来源等信息仍保留在海报下方。
- 不裁剪和拉伸源图；2:3 框架内完整显示，背景填充只承担留白。
- 评分仍使用原有绿 / 黄 / 红 10 分制方块，**始终是当前用户的分数**，不是 Bangumi 或圈子均分。
- 关于旧封面：如果黑色英文文字本身已经画在第三方图片里，前端不会擅自裁剪原始图片。此次移除的是由页面或预览素材增加的覆盖层。

## 2. COLLECTION 首页 → 流动海报墙

- 原右侧固定的四张作品展示卡更换为 **3 列纵向流动海报墙**，整体为炭黑、深松绿、低饱和灰，弱化装饰。
- 数据来自 `catalog_items` 加载后的 `data.items`：只取有封面 URL 的游戏与动画，最多 18 个不同条目；优先考虑已有圈内评分的作品。
- 三列速度不同并交错滚动；鼠标停留或键盘聚焦时暂停，点击原始海报可打开对应作品详情。
- 内部使用 CSS transform，不新增 WebGL 或外部搜索请求；移动端降低滚动速度。
- 系统设置“减少动态效果”时完全停止滚动；缺少可用封面时显示友好的空状态。
- 这个改动仅应用于 COLLECTION 主题，VIDEO CLUB 原本的首页场景和 VHS 陈列不受影响。

# 同频 V0.5.9 · COLLECTION / Field Notes

基于 V0.5.8 的定向改进。**不需要新的 Supabase SQL**（从 V0.5.6 或更早升级仍需先执行 V0.5.7 的帖子迁移）。

## 本次更新

- 海报墙个人评分改为**不含 MY 的黑体方形评分块**，绿色 8–10，黄色 6–7.5，红色 0.5–5.5；评分为用户自己的 10 分制，不是 Bangumi 或圈内分数。海报仍然完整显示原图。
- COLLECTION 主题换为独立的暖纸张 / 松绿编辑式设计，顶部胶囊导航、软质面板、微倾斜海报拼贴、柔和阴影；VIDEO CLUB 原样保留。
- 批量导入保留共享库优先匹配，在解析完成后**自动对首批最多 8 条未匹配记录联网搜索**，其余点击“继续匹配”分批查询，以防几百条记录同时请求造成慢速或触发上游限流。
- 每条联网搜索返回至多 3 个候选，结合名称 / 类别 / 年份排序；用户**必须手动选择候选**才能使用其资料建档。未确认候选不自动入库。仍找不到的条目只有在明确勾选允许手动建档后才会写入共享库。
- 候选会携带可用的封面、平台与来源信息，保留旧记录、不覆盖已有个人评分。默认仅自己可见，只有主动勾选后才圈内公开。

## 数据来源与限制

调用项目已有的 `/api/search`（按类别分别搜索动画或游戏），由服务器访问 Bangumi、可用的 Jikan / IGDB / RAWG 等。具体结果取决于部署环境的网络状况和可选来源是否配置 API Key。**没有接入 Steam 商店。** 上传的文件留在当前浏览器，只有查询关键词会经过同频服务端发送到上游数据源。

对于旧数据中未匹配的作品，本版本不会擅自按相似标题导入错版作品。源站不可用时可以重试或选择手动建档。

## 更新 GitHub

- 直接用完整项目包覆盖仓库文件，保持 `src/`、`api/`、`public/` 等目录结构。
- 从 V0.5.8 升级可以只覆盖补丁中的文件。
- **无需修改环境变量或执行新 SQL**。
- 用 `npm ci`（有锁文件时）或 `npm install`，然后 `npm run build`；此外执行 `npm run test:search`、`npm run test:features`。

## 验证范围

52 项既有搜索/封面/分页测试 + 13 项功能测试全部通过；Chromium 测试两套主题的首页和收藏页、桌面/390px 手机海报墙、CSV 自动候选确认，未见 JavaScript 错误或横向溢出。本环境没有可用的 Vite 安装，未完成生产构建、实际 Supabase 写入及真实第三方 API 联调。

# 同频 V0.5.8 · POSTER INDEX

延续 VIDEO CLUB 录像店，同时把 COLLECTION 升级为真正独立的编辑式影像资料库主题。

## 核心新增

- **个人海报墙**：MIXTAPE / 海报墙 / 详细列表，三视图自由切换。海报墙每页 24 项，兼容分类、状态和排序，封面不拉伸。
- **帖子作品搜索**：搜索中文名或原名，显式选中作品后才能发帖，避免大下拉框或误选。
- **圈内帖子上首页**：最新 3 帖展示在首页的好友动态下方，包含作品、作者、回复数和剧透隐藏。
- **下载导入模板**：导入弹窗内直接下载 Excel (.xlsx) 或 CSV。
- **真正的双主题**：VIDEO CLUB 保留复古录像店；COLLECTION 使用独立的图文编辑布局、深松绿、米白、收藏卡和海报资料库。

## 部署

- 从 V0.5.7 升级：**无需新的数据库迁移，也无需新增环境变量**。
- 从 V0.5.6 或更早升级：请先在现有 Supabase 项目执行 `supabase/migration_v057.sql`，以创建并保护帖子/回复表。
- 将完整源码的内容放到 GitHub 仓库根目录。不要把整层 `tongpin-v058/` 套进去，亦不要上传真正的 `.env` 或服务器密钥。
- 提交后等 Vercel 自动构建，建议检查两套主题、发帖绑定及帖子在首页出现的情况。

细节和测试步骤见 [docs/FEATURES_V058.md](docs/FEATURES_V058.md)。
