# 同频 V0.4.6 — The Living Library / 流动藏书馆

## 更新方式

在已部署 V0.4.5 的 GitHub 仓库中，把 `v046-upgrade-patch.zip` 的文件依路径覆盖，并提交。Vercel 会自动构建。**不需要执行数据库 SQL，Supabase、账号和圈子数据均保持不变。**

若从更早版本升级，推荐直接使用完整 ZIP，并确认 V0.4 和 V0.4.5 数据库迁移已执行：`supabase/migration_v04.sql`、`supabase/migration_v045.sql`；不要在有数据的数据库重跑 `schema.sql`。

## 设计系统

- 主题：现代藏书馆，保留浅色外观；背景为羊皮纸/象牙白，左侧索引为深松绿，交互重点用黄铜金。
- 排版：中文正文优先系统无衬线，叙事标题使用系统宋体/衬线回退，不下载外部字体，考虑大陆用户加载速度。
- 首页：拱形馆藏大厅；纯 CSS 制作浮动书本与柔光；真实圈内评价驱动精选墙和动态。
- 我的：3D 书页、书脊、书本抬起/旋转；游戏和动画分架展示，旅行地点采用旅行卡；保留列表模式。
- 作品详情：把封面放入纸页立体结构，原 Bangumi 评分和圈内评分依旧分开展示。
- 动效：进入视野轻淡入、书本 pointer 倾斜、首页灯光慢漂移；移动触控/减少动态效果/降低性能条件自动关闭持续动画。

## 不变的业务功能

- Supabase 邮箱密码登录、注册、圈子邀请码、RLS。
- Bangumi 游戏与动画搜索、IGDB 游戏补充、高德地点搜索和封面代理。
- 个人体验与隐私、作品详情、评分榜与「至少 3 人评价」筛选。
- 原来 V0.4.5 的 `bangumi_score`、平台和标签逻辑不变，不改动数据库。

## 运行

```sh
npm install
npm run dev
npm run build
```

请继续使用 Vercel 现有环境变量；本版没有新增密钥和环境变量。若在本地使用搜索服务，照旧按原 README 的 `npm run dev:search` 配置。

## 预览与验证

- `design-preview.html` 是**独立的交互视觉样稿**，带模拟记录和自制 SVG 封面，**不连接 Supabase、不模拟真实评分结果**。与原工程在同一目录，可在浏览器打开。
- 开发和 API 测试在本地均可运行；当前制作环境成功执行 37 项 Node 测试和 JavaScript 语法检查。
- 当前环境的自动化 Chromium 导航被管理员策略拦截，**没有完成 Vite 实际构建、电脑/手机截图与线上 Vercel 联调**。需要在本地 `npm run build` 之后上线检查。
- 手动测试：手机 375px / 390px，桌面 1366px / 1440px，点击五个导航、收藏书本、作品详情、动态和筛选；打开系统「减少动态效果」检查动画停止。

## 访问与性能

- 首页插画书本使用纯 CSS，不加载第三方图片和字体。
- 真实书本封面继续使用既有 `/api/cover` 代理，并延迟加载。
- `IntersectionObserver` 只在元素进入视口时触发动画。小屏/触控自动关闭连续漂浮动画。
- 对中国大陆而言，页面可以减少视觉层的第三方请求，但 Supabase、Bangumi 和 Vercel 的网络连通性仍然需要实际测试；Cloudflare 橙云无法保证这些链路全部稳定。
