# V0.5.8 · POSTER INDEX & EDITORIAL COLLECTION

## 从 V0.5.7 升级

1. 直接覆盖补丁中同路径文件，或从完整源码包更新 GitHub 根目录。
2. **不需要运行新的 Supabase SQL**；但从 V0.5.6 及更旧版本直接升级时，必须先在已有 Supabase 项目执行 `supabase/migration_v057.sql`。切勿重新初始化数据库。
3. Vercel 环境变量保持原样。

## 新功能

- 我的录像柜：`MIXTAPE` / `海报墙` / `列表` 三种视图。海报墙每页 24 件，游戏/动画复用现有筛选、状态和排序；切换筛选回第一页。封面保持原比例（`object-fit: contain` + 背景填充），不强制裁切。
- 帖子编辑：支持中文名、英文名、别名和部分标签的本地搜索。必须显式选择一件已在共享库的游戏或动画，隐藏 `itemId` 才会写入表单；输入其他搜索词会清除已选作品。没有搜索结果可先去「找片」导入。
- 首页：加载圈内已发表的最近 3 个帖子，包含作者、作品、更新时间、回复数与剧透遮挡；点击跳转对应帖子。保留原有评分动态。
- 一键导入：批量导入弹窗新增 `Excel 模板` 与 `CSV 模板` 下载，静态文件位于 `public/templates/`。Excel 第一工作表应放待导入记录。
- COLLECTION：独立编辑式首页（深松绿/暖米白、错位封面拼贴与杂志排版），新的藏品界面使用海报墙作为默认展示，讨论区视觉与 VIDEO CLUB 明显不同。两套主题共用全部数据库记录，主题偏好持久化到浏览器 `localStorage`。

## 测试

```
npm run test:search
npm run test:features
npm run build
```

帖子 RLS 依赖 `migration_v057.sql`，新版本不放宽任何数据库权限；客户端只能读取当前已加入圈子的帖子。
