# V0.6.3 安全默认选择规则

这次修复 V0.6.2 的关键问题：表格解析器默认将所有合法行标记为 `selected:true`，而网络搜索队列也只搜索已勾选的行。这造成了无结果、同名候选未审等行被默认选中。

新版本引入 `src/importSelection.js`，把「是否要搜索」与「是否可导入」独立管理。

1. 初始化：`row.match` 已唯一匹配且无行错误时默认勾选；其余行先不勾选。
2. 联网搜索：`getImportLookupJobs` 会搜索所有无错误、未本地匹配、状态为 `queued` 的行，不看 `selected`。继续保持最多两个并发与限速。
3. 网络成功：若 `evaluateImportMatch` 返回唯一的高置信度 `choice`，默认勾选；否则保留未勾选。
4. 手动选中网络候选：`confirmImportCandidate` 把该行标记为已确认并自动勾选；清除候选则恢复未勾选。
5. 使用者主动取消勾选，后续异步匹配结果不会强制反选为选中。
6. 搜索失败／无候选：默认禁用勾选。若明确开启手动建档，行可由用户主动勾选；再次关闭手动建档时这些行恢复未勾选。
7. 最终确认：重新验证每行 `canSelectImportRow`，仅对明确勾选的有效行写入数据库。已有个人记录保留跳过逻辑。

**测试**：`npm run test:features` 包含纯函数测试；`npm run test:search` 覆盖服务端搜索。
