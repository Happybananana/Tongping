# 同频 V0.4.9 · AFTER HOURS / 四处设计升级

基于 V0.4.8（已经包含 Supabase 密码登录、Bangumi/IGDB/高德服务端搜索、圈子成员评分）。**没有改变数据库、后端 API、环境变量或鉴权权限**。

## 页面变更

1. **店内放映 / 朋友正在播放**：保留原首页 hero。体验评分改成粗字重、黄底黑框、黑色铸字风格的 `MY SCORE` 数字租片标签；数值仍来自用户真实评分，并非 Bangumi 社区分。
2. **找片**：把输入框提升为搜索调谐台。输入后在页面上方的店内现货区域**即时筛选 Supabase 已有条目**。在「游戏」「动画」「地点」频道输入 2 个及以上字符，前端等待 320ms 后再调用原有经身份验证的 `/api/search`，结果展示在同页面下半部分的「新片到货」。点击「加入并评分」仍走 V0.4.8 的创建/去重/记录流程。选择「全部」时只检索本地馆藏，避免同时查询三种第三方服务。提供 3 个用于填充关键词的示例按钮，在线 API 未配置时仍支持手动建档。
3. **好友频道**：去掉冗余的标题面板，增加唱片电台入口；榜单前三名进入 1 大 2 小的不对称播送舞台，其余进入曲目列表。原本的「全部/游戏/动画/地点」「默认所有至少 1 人评分」「至少 3 人评分」和「平均分 / 分歧」筛选**均保留且仍为真实计算**。额外展示一个基于真实评分极差的「本周争议」条目（至少 2 人评分时显示），成员以放映员小卡呈现。
4. **我的录像柜**：取消大面积规则网格。顶部精选当前筛选条件下评分最高（没有分数时按最近更新）的作品作为「NOW ON DECK」主打磁带。游戏、动画各有可横向滑动与 scroll-snap 的录像带展架；地点仍以旅程票根展示。保留筛选、个人评分排序、磁带馆 / 列表切换、所有账号管理功能。

## 使用方法

- 将增量补丁覆盖 V0.4.8 项目同路径文件并提交 GitHub；Vercel 会自动构建。
- 本次**无需执行新的 SQL**；已导入条目、隐私规则、圈子排行榜不变。
- `visual-preview.html` 是完全离线的独立演示页面，使用 6 个模拟条目，不连接 Supabase。正式页面仍通过 `src/main.js` 读取真实数据。

## 验证

- `node --check src/main.js` 通过。
- `npm run test:search`：37/37 测试通过。
- Playwright + Chromium 对离线预览进行了桌面 1440px、手机 390px 四个页面的截图检查；无脚本异常、无横向溢出。测试了本地关键词即时过滤与榜单 >=3 人筛选的交互（**仅预览模拟数据**）。
- 未在真实 Supabase 账号 / 生产 Vercel 上做回归；仍需本地运行 `npm install && npm run build`，上线后实际验证跨账号 RLS、搜索返回、作品导入、列表/磁带视图与手机号浏览器性能。

## 设计与性能注意

- 主页大场景资源没有改变；没有引入新的第三方字体、图片或动画库。
- 唱片旋转动画在移动端和触控设备禁用；系统的 `prefers-reduced-motion` 也可关闭新动效。
- 录像带货架采用原生触控横向滚动，不使用 WebGL，减少移动设备开销。
- Bangumi 官方分与朋友评分完全独立；圈子榜只按成员公开评分计算。
