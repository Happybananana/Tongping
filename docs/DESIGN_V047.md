# V0.4.7 · 沉浸式图书馆前端重构

## 改造目标

消除 V0.4.6「纯色背景 + 固定侧栏 + 等宽卡片」的重复感。采用有空间叙事的首页：

- **馆内入口**：本地图书馆拱廊插画 `public/atrium.svg`、近远景遮罩、光斑追踪、缓慢视差、编辑式大标题。
- **馆内章节**：带角度的横向藏书标识、非对称章序引言，以及使用真实圈内评分驱动的「本期共鸣」藏品卡。
- **馆藏橱窗**：1 张主视觉 + 3 张不同尺寸的辅助封面卡；卡片可点击查看详情。
- **朋友动态**：由固定堆叠改成纸张档案式错列双栏，手机改为正常单列。
- **统一导航**：桌面顶部横向索引；手机继续使用底部导航；各处保留记录、发现与评分入口。
- **个人藏馆**：拱廊展厅式书墙，加强内壁与台架纵深感，真实个人封面继续从 Supabase 条目加载。
- **其他页面**：发现、圈子、我的采用具有空间层次的章节标题；详情与榜单沿用原有功能与数据。

## 设计原则

1. 动效仅对 `transform`、`opacity` 和少数 CSS 变量做变化；不创建 canvas/WebGL 长驻动画。
2. 只在视窗内更新英雄场景的视差；`prefers-reduced-motion: reduce` 下关闭动态位移。
3. 手机端取消鼠标视差和复杂悬停，场景 SVG 随代码部署；无 Unsplash 等新增远端图片依赖。
4. `visual-preview.html` **仅包含模拟数据**，用来审美验收，不会连接或修改真实 Supabase。

## 如何升级现有 Vercel 项目

从 V0.4.6 升级，使用补丁包覆盖以下文件并提交到 GitHub：

- `index.html`
- `src/main.js`
- `src/immersive-theme.css`（新增）
- `public/atrium.svg`（新增）
- `public/manifest.webmanifest`
- `package.json`

完整包内已包含这些文件。**无需执行 SQL / 重新配置 Supabase / 修改 Vercel 环境变量**。已有用户、圈子、Bangumi 搜索、评分榜和「至少三人评分」开关不改。
