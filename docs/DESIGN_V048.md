# 同频 V0.4.8 · VIDEO CLUB 视觉重塑

## 方向

不复刻《绝区零》或《女神异闻录4》的具体界面、品牌、角色或受保护插图，只提炼两类可复用的视觉思想：**实体录像店的陈列与街头拼贴**、**模拟电视信号和大胆的明黄黑色图形**。

- 背景：原创、本地打包 SVG 录像店场景（`public/video-store.svg`），不用境外素材 CDN。
- 风格：奶油白、明黄、深墨黑、信号红、青绿；超粗排版、细节标签、斜向磁带。
- 首页：像橱窗陈列而非中后台；顶部保留用户熟悉的菜单和快速记录操作。
- 个人记录：游戏与番剧的立体 VHS 盒墙；旅行用票据卡片，不改变条目数据结构。
- 共友榜单：保持默认显示所有已评分作品，开关仍是 **至少 3 人评价**。
- 条目详情：原 Bangumi 社区评分和同频圈内评分仍独立。

## 代码变更

1. `src/main.js`：替换展示文案、首页大视觉和 VHS 陈列标签；**业务请求、认证、评分与筛选逻辑均不改变**。
2. `src/videostore-theme.css`：新视觉与动效，保留 `library-theme.css` 中的通用陈列结构并在最后覆盖。
3. `index.html`：品牌名、导航入口、主题色。
4. `public/video-store.svg`、`public/icon.svg`、`public/manifest.webmanifest`：原创本地资源。
5. `visual-preview.html`：独立视觉原型，演示数据，不连接 Supabase。

## 安装部署

- 基于 V0.4.7 更新；没有 SQL 变更，也不需要修改 Vercel 环境变量。
- 将补丁中的文件保持路径覆盖到 GitHub 项目，提交后 Vercel 自动部署。
- 仍然使用 `npm install`、`npm run build` 进行本地构建。
- 建议先在 Vercel Preview 部署预览，不要直接覆盖正在给朋友使用的生产环境。

## 性能策略

- 商店场景、图标使用本地 SVG，减少跨境额外请求。
- 首屏 VHS 拼贴无外部图片请求，内容封面继续使用已有 Bangumi 代理。
- 手机端降低动画复杂度；支持 `prefers-reduced-motion`。
- 注意主页主视觉的 CSS 层次较多，建议在低端 Android 实机和三大运营商网络上做进一步性能评估。

## 验证

- `node --check src/main.js` 成功。

- 浏览器静态预览已验证桌面和手机端基本排版、主要导航，无横向溢出。
